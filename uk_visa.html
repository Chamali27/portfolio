// Project Overview

This project analyzes the UK Home Office's Managed Migration Historic datasets, focusing on Study and Work Sponsorship visa records. Using SQL Server for data storage and transformation, and Power BI for visualization, the team built an interactive dashboard that reveals migration trends, nationality patterns, and sponsorship outcomes across 14 years of data.

Team: WACI Abeysekara  ·  RL Hewanayaka  ·  MZM Hussein  ·  MN Mohamed

// Key Questions Explored

Which nationalities apply most for UK study and work visas?
How have visa applications trended from 2010 to 2024?
What are the approval, refusal, and extension rates over time?
Which industries and institution types drive the most applications?

// Methodology

01
Data Collection

Downloaded Study & Work Sponsorship datasets from Data.gov.uk (UK Home Office open data), covering 2010–2024.

02
Data Storage & Cleaning

Imported into SQL Server. Standardized column names, fixed data types, and created 4 clean tables: Study/Work by Nationality and by Institution/Industry.

03
Data Modelling

Built relationships in Power BI across Year, Visa Type, Nationality, and Industry. Created custom DAX measures for totals, approvals, and extensions.

04
Dashboard Design

Built interactive Power BI dashboards with slicers, drill-throughs, tree maps, and line/bar charts for end-to-end exploration.

// Key Insights

📈
Study visas peaked in 2023–2024, showing strong post-COVID recovery in UK international education.
🌏
China (~1.69M) and India (~1.44M) are the largest source countries for UK visas.
🏥
Work visas surged post-2020, driven by demand in health, IT, and professional services.
🎓
UK universities remain the main drivers of international student visa sponsorship.
📋
Visa extensions increased after 2021, indicating longer stays and continued sponsorship.
📉
Work visas dipped in 2017–2018 due to Brexit uncertainty, then recovered post-2020.
