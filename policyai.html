// Project Overview

PolicyAI is a fully functional web application built with Python and Streamlit. The system enables users to upload or paste any real-world policy document, generate a structured NLP summary highlighting goals, key measures, and overall direction, and then produce scenario-adapted policy drafts using a locally hosted LLM (llama3.2 via Ollama). The application was built around SriLankan Airlines' Conditions of Carriage as the primary policy document.

Team: WACI Abeysekara  ·  RL Hewanayaka  ·  MZM Hussein  ·  MN Mohamed

// Key Questions Explored

How can NLP reduce a complex policy document into a structured, readable summary?
How does context change when a policy is adapted for a different audience or regulation?
Can a locally hosted LLM generate coherent, scenario-specific policy drafts?
How should a dual-panel web application be designed for policy analysis workflows?

// Methodology

01
Policy Input & Text Extraction

Supports three input modes — file upload (PDF, DOCX, TXT, JSON), paste text, and built-in sample policies. Text extraction handles multiple formats using PyPDF2 and python-docx.

02
NLP Preprocessing & TF-IDF Summarisation

Sentence tokenisation using NLTK, stopword removal, token filtering, and TF-IDF scoring to rank and extract the most meaningful sentences. BART transformer used as fallback if available.

03
Structured Section Extraction

Keyword-based scoring separates the summary into three structured sections: Main Goals, Key Measures & Strategies, and Overall Direction — for clarity and usability.

04
Scenario Definition & Generative Drafting

Users define custom scenarios or use pre-filled prompts. The structured summary is passed to llama3.2 via Ollama's local REST API, which generates a formal adapted policy draft per scenario.

05
Web Application & Export

Dual-panel Streamlit interface: left panel for summarisation, right panel for scenario-based drafting. Supports multiple concurrent scenario slots, regeneration, and download of all outputs.

// Key Insights

📄
TF-IDF extractive summarisation successfully reduced a 2,000+ word policy to a structured 3-section summary while preserving key legal and operational meaning.
🤖
llama3.2 via Ollama generated coherent, professional-tone policy drafts locally — requiring no cloud API, preserving data privacy, and enabling offline use.
🎯
Scenario-based prompting produced clearly differentiated outputs — the same policy adapted for passengers with disabilities vs. Canadian APPR compliance yielded structurally distinct drafts.
⚙️
Keyword scoring for section extraction (goals, measures, direction) proved effective as a lightweight alternative to fine-tuned classification models for structured document analysis.
🌐
The dual-panel interface allowed iterative exploration — users could modify scenarios, regenerate drafts, and download multi-scenario reports without restarting the workflow.
💡
The system demonstrates how AI tools can support policy communication — not by creating new legislation, but by adapting existing content for different audiences and regulatory contexts.

// Tech Stack

🐍
Python & Streamlit

Core application framework. Streamlit handles the dual-panel UI, session state management, file uploads, and interactive controls without requiring a separate frontend.

📝
NLTK & TF-IDF

Natural Language Toolkit for sentence tokenisation and stopword removal. Custom TF-IDF implementation scores and ranks sentences for extractive summarisation.

🦙
Ollama + llama3.2

Locally hosted large language model accessed via REST API on localhost:11434. Generates scenario-adapted policy drafts with structured prompts using professional policy language.

📦
PyPDF2 & python-docx

Document parsing libraries for extracting raw text from uploaded PDF and DOCX files, enabling the system to work with real-world policy documents in any common format.
