// Project Overview

PolicyAI is a fully functional web application built with Python and Streamlit. The system enables users to upload or paste any real-world policy document, generate a structured NLP summary highlighting goals, key measures, and overall direction, and then produce scenario-adapted policy drafts using a locally hosted LLM (llama3.2 via Ollama). The application was built around SriLankan Airlines' Conditions of Carriage as the primary policy document.

Team: WACI Abeysekara  ·  RL Hewanayaka  ·  MZM Hussein  ·  MN Mohamed

// Key Questions Explored

How can NLP reduce a complex policy document into a structured, readable summary?
How does context change when a policy is adapted for a different audience or regulation?
Can a locally hosted LLM generate coherent, scenario-specific policy drafts?
How should a dual-panel web application be designed for policy analysis workflows?

// Methodology

01
Data Input & Extraction

Supports PDF, DOCX, TXT, JSON, or pasted text using PyPDF2 and python-docx.

02
Text Processing & Summarisation

NLTK preprocessing with TF-IDF scoring to extract key sentences; BART used as fallback.

03
Structured Extraction

Keyword scoring splits summaries into goals, measures, and overall direction.

04
Scenario-Based Generation

llama3.2 (Ollama) generates tailored policy drafts from scenario prompts.

05
Web App & Export

Streamlit interface enables multi-scenario generation and report downloads.

// Key Insights

📄
TF-IDF summarisation reduced 2,000+ words into a structured 3-section summary.
🤖
llama3.2 (Ollama) generated privacy-preserving, offline policy drafts.
🎯
Scenario-based prompting produced distinct policy outputs for different contexts.
⚙️
Keyword scoring effectively structured document sections without complex models.
🌐
Interactive interface enabled iterative scenario editing and report generation.
💡
AI adapts policy content for different audiences and regulatory contexts.
