// Project Overview

This project focuses on predicting road accident severity using supervised machine learning techniques. Accident severity was modeled as a binary classification problem, distinguishing between high-severity and low-severity accidents based on environmental, weather, and road infrastructure features from the US Accidents dataset (2016–2023).

Team: WACI Abeysekara  ·  RL Hewanayaka  ·  MZM Hussein  ·  MN Mohamed

// Key Questions Explored

Can machine learning accurately predict road accident severity?
Which factors contribute most to severe accidents?
How do environmental conditions affect accident outcomes?
Which model performs better: Logistic Regression or Random Forest?

// Methodology

01
Data Collection

Used the US Accidents dataset (2016–2023) containing over 7.7 million accident records across the United States.

02
Data Preprocessing

Handled missing values, encoded categorical variables, and selected key features relevant to severity prediction.

03
Feature Engineering

Converted severity into binary classes (high vs. low) and narrowed the feature set to 12 most important predictors.

04
Model Training

Applied Logistic Regression and Random Forest classifiers with a stratified 80/20 train-test split.

05
Evaluation

Assessed model performance using Accuracy, Precision, Recall, F1-score, and Confusion Matrix analysis.

// Key Insights

⚠️
The dataset is highly imbalanced, with high-severity accidents representing a small minority of all records.
🌲
Random Forest significantly outperforms Logistic Regression in detecting high-severity accident cases.
📉
Logistic Regression struggles with the minority class, producing poor recall for high-severity predictions.
🌧️
Weather conditions, temperature, and visibility are among the strongest predictors of accident severity.
📏
Accident distance and humidity levels emerge as key quantitative predictors in the trained models.
🚦
Road infrastructure features such as junctions and traffic signals play a secondary but meaningful role.
