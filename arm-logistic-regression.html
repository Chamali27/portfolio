// Project Overview

This project explores how data mining techniques can be applied across two different industries. Association Rule Mining (ARM) was used to analyze online retail transactions and identify product purchase patterns, while Logistic Regression was applied to healthcare data to predict patient readmission within 30 days. Both analyses were implemented in R, combining statistical rigor with practical business and clinical applications.

Team: WACI Abeysekara  ·  RL Hewanayaka  ·  MZM Hussein  ·  MN Mohamed

// Key Questions Explored

What product combinations are frequently purchased together?
How can ARM support marketing and product bundling strategies?
Can logistic regression reliably predict patient readmission?
Which factors most influence hospital readmission risk?

// Methodology

01
Data Preparation

Cleaned retail and healthcare datasets, removed missing values, handled outliers, and engineered relevant variables for modelling.

02
Association Rule Mining

Applied the Apriori algorithm to retail transaction data using support, confidence, and lift thresholds to discover meaningful product purchase patterns.

03
Logistic Regression

Built a binary classification model on 10+ years of patient records to predict the likelihood of 30-day hospital readmission.

04
Model Evaluation

Assessed performance using confusion matrix, ROC curve, and AUC score, identifying areas limited by class imbalance in the data.
